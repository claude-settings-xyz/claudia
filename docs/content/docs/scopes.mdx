---
title: Scopes and files
description: Which files Claudia reads and writes.
---

Claude Code reads its configuration from more than one place. Claudia calls each place a scope.

## Global

Global files apply to all your projects.

| File                      | Purpose                                   |
| ------------------------- | ----------------------------------------- |
| `~/.claude/settings.json` | Your global settings.                     |
| `~/.claude/CLAUDE.md`     | Instructions for Claude in every project. |

## Project

Project files apply to one folder.

| File                                   | Purpose                                                       |
| -------------------------------------- | ------------------------------------------------------------- |
| `<folder>/.claude/settings.json`       | Shared project settings. Commit this file.                    |
| `<folder>/.claude/settings.local.json` | Your personal project settings. Keep this file out of git.    |
| `<folder>/CLAUDE.md`                   | Instructions for Claude in this project.                      |

If `<folder>/CLAUDE.md` does not exist but `<folder>/.claude/CLAUDE.md` does, Claudia edits that file instead.

## Precedence

When the same setting is in more than one file, Claude Code uses this order:

1. Local project settings
2. Shared project settings
3. Global settings

The first file in the list wins. Managed settings from your organization and command-line flags override all three.

## Project list

Claudia takes your projects from `~/.claude.json`, which lists every folder where you used Claude Code. It only shows the folders that have a settings file or a `CLAUDE.md`. The most recently used folders come first.

To manage a folder that is not in the list, add it with the **+** button. Type its path, or choose **Select folder** to pick it in your system's folder dialog. On Linux, the dialog needs `zenity`, `qarma` or `matedialog`. Folders that you add stay in the list, even without Claude files.

Your home folder is not in the list. Its `.claude` folder holds the global files, so you edit them under **Global**.

## Custom config directory

Claudia respects the `CLAUDE_CONFIG_DIR` environment variable. If you set it, Claudia uses that directory instead of `~/.claude`. It also reads `.claude.json` from inside that directory, not from your home folder.

## Saving

- Settings files must contain valid JSON. Claudia does not save invalid JSON.
- Claudia writes each file atomically. A failed save does not leave a half-written file.
- If a file changed on disk after you started editing, Claudia does not save. For example, Claude Code may have written to it. Choose **Load theirs** to discard your edits, or **Keep mine** to save over the new version.
- If you have unsaved changes, Claudia asks before you switch to another folder.
