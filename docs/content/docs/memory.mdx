---
title: Memory
description: Read, edit and delete the auto memory notes that Claude Code saves about each folder.
---

Claude Code can save notes as it works, such as how to deploy or which approach failed before. This is auto memory. Claude keeps it for each folder that you start Claude Code in.

## Where memory lives

By default, the notes of a folder are in `~/.claude/projects/<folder>/memory/`. `MEMORY.md` is the index that lists the other notes. Claudia shows it as **Index**.

If you set `autoMemoryDirectory` in your global settings or in the local settings of a project, Claudia reads the notes from that folder. Claude Code ignores this setting in the shared `.claude/settings.json`, and so does Claudia.

With no project selected, **Memory** shows the notes from sessions that you started in your home folder.

## Edit and delete notes

Select a note to edit it. To delete a note, choose **Delete**. You cannot delete the index. After you delete a note, the index may still mention it until Claude updates the index.

## Turn auto memory on or off

Set `autoMemoryEnabled` to off in **Configuration**, globally or for one project. **Memory** says when auto memory is off.

To turn it back on, choose the button in **Memory**:

- In a project, **Turn on for this project** sets `autoMemoryEnabled` to on in `.claude/settings.local.json`. That file wins over the shared and global settings, and only you use it.
- In the global view, **Turn on auto memory** removes `autoMemoryEnabled` from `~/.claude/settings.json`, so auto memory is on again by default.
